# Site Grand Prix de Monaco

Selim Rebai et Raphael Simon - projet Web TI504N (EFREI)

## Fichiers

- `index.html` : accueil
- `pages/` : histoire, circuit, palmarès, billetterie, à propos
- `css/style.css` : le style
- `js/script.js` : menu mobile + mode sombre
- `js/accueil.js` : carrousel + compte à rebours
- `js/circuit.js` : boutons « En savoir + »
- `js/palmares.js` : recherche dans le tableau
- `js/billetterie.js` : prix + vérification du formulaire

## Photos

Les photos viennent d'Unsplash (Wyatt Simpson, licence libre) et le plan du circuit de Wikimedia Commons.
Elles sont chargées depuis internet : il faut être connecté pour les voir.
